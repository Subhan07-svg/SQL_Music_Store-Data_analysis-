# 🎵 Music Store Data Analysis Project

## 📌 Project Overview

The Music Store Data Analysis Project focuses on analyzing a digital music store's database to understand customer purchasing behavior, music sales, artist performance, and revenue trends.

The project uses relational database tables and SQL queries to extract meaningful insights from music store data. It helps demonstrate practical SQL skills, data analysis techniques, and the ability to solve business-related questions using data.

## 🎯 Project Objectives

- Analyze customer purchasing behavior and spending patterns.
- Identify top-selling tracks, albums, artists, and music genres.
- Calculate total revenue and analyze sales performance.
- Understand customer distribution across different countries.
- Identify high-value customers based on their purchases.
- Analyze employee information and customer support relationships.
- Practice SQL joins, aggregations, subqueries, and other database concepts.

## 🛠️ Tools and Technologies

- **SQL** – Data querying and analysis
- **Relational Database** – Storing and managing structured data
- **CSV Files** – Source data for database tables
- **GitHub** – Project documentation and version control

## 📂 Dataset Description

The project contains the following datasets:

| Dataset | Description |
|---|---|
| `album.csv` | Album details and artist IDs |
| `album2.csv` | Additional album data |
| `artist.csv` | Artist names and IDs |
| `customer.csv` | Customer details and contact information |
| `employee.csv` | Employee information and reporting structure |
| `genre.csv` | Music genre details |
| `invoice.csv` | Invoice dates, billing information, and totals |
| `invoice_line.csv` | Invoice items, track prices, and quantities |
| `media_type.csv` | Types of music media |
| `playlist.csv` | Playlist information |
| `playlist_track.csv` | Relationships between playlists and tracks |
| `track.csv` | Track names, albums, genres, duration, and prices |

The ZIP folder also includes a database schema diagram showing the relationships between the tables.
